# Live Trading Notes

这套工具第一版只用于学习、研究、回测和生成手动交易计划，不包含自动下单。

## 为什么先不做自动下单

A 股程序化交易已经有明确监管框架。个人投资者使用计算机程序自动生成或下达交易指令时，应先和开户券商确认：

- 是否属于程序化交易申报范围
- 券商是否提供正式接口
- 是否需要报告账户、策略、软件、频率等信息
- 高频申报、撤单、异常交易、涨跌停参与等限制
- 日志留存和风控要求

## 建议的实盘路径

1. 先用本项目生成每日或每月交易计划。
2. 手动核对停牌、涨跌停、重大公告、业绩预告和持仓风险。
3. 手动下单并记录实际成交。
4. 把真实持仓导出为 `positions.csv`，用于下一次生成交易计划。
5. 只有在合规确认后，再新增券商官方接口模块。

## 风控底线

- 单票上限、行业上限和现金缓冲必须保留。
- 不要用回测收益替代风险评估。
- 不要把样例数据的结果当作策略有效性证据。
- 每次改策略后，都要重新检查是否引入未来函数。
